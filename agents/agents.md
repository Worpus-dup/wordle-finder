# Wordle-Finder

## Tech Stack
- Language: Rust
- Framework: no-framework
- Database: no-database

## Key Rules
- Ask before any essential change.
- Before starting the work create the plan.
- Simplicity is the key.
- TDD. Tests go before the code.

## Workflow
- Plan mode: Don't plan + execute simultaneously.
- Stop and ask: When encountering unaddressed design decisions.
- Run tests: Verify with `cargo test` before marking tasks complete.
- Review points: Let user review before proceeding to next step.
- Deviation tracking: Document changes from task plan.

## When Stuck
Ask before making architectural changes.
